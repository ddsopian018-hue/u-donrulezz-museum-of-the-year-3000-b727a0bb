Museum of the Year 3000 — a single deadpan museum label for an ordinary object from today. The program writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`: the year-3000 label beside a pine-tree car air freshener, misread by a future curator as a ritual charm for summoning forests into a steel box. Fresh object, fresh angle — no fork, no parking meter, no house key.

## Run it

```sh
node main.ts
```
